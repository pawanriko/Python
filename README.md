## How it's arranged

```
Python/
```

## Module 1 — the basics (done)

- Type conversion
- Practice exercises

## Run any file like this

```bash
git clone https://github.com/pawanriko/Python.git
cd Python
python3 "python/Module 1/00_Hello_World.py"
```

Same for the rest — just change the file name.
